# H01 — AFS Spectroscopy Assessment

## Customer Enquiry

Our existing NIR pilot follows API concentration in one powder formulation at the tablet press feed frame. We are introducing a different API and excipient blend and would like to reuse the calibration. A colleague suggests adding Raman so that the old calibration will remain valid. What should our first technical assessment and experiment be?

---

## Requirements & Key Facts

**What the client stated:**
- Existing NIR pilot monitors API concentration at tablet press feed frame
- Current application: one powder formulation (API + excipients)
- Planned change: different API and different excipient blend
- Client goal: reuse existing NIR calibration for the new formulation
- Colleague's suggestion: add Raman to make the old calibration remain valid

**Key unknowns:**
- Identity of the current and new API (chemical structure, spectral features)
- Identity of current and new excipients
- Whether the new API and excipients have similar or different NIR/Raman spectral signatures to the original
- Concentration range of API in the new formulation
- Whether reference assay (e.g. HPLC) is available for the new formulation
- Physical properties of the new blend (particle size, density, flow behaviour)

---

## Clarification Questions

1. What is the chemical identity of the current API and the new API? Are they structurally similar (e.g. same functional groups) or chemically distinct?

2. What are the main excipients in the current blend versus the new blend? Are any components shared?

3. What is the target API concentration range in the new formulation, and does it overlap with the calibration range of the existing model?

4. Is an independent reference method (e.g. HPLC) available and validated for the new API in the new matrix?

5. Are there known physical differences (particle size distribution, bulk density, flow properties) between the old and new blends that could affect the NIR diffuse reflection signal?

---

## Recommendation

**Decision Status:** Provisional assessment

**Critical correction of the client's premise:**

The premise that the existing NIR calibration can be reused for a different API and excipient blend is **incorrect**. Calibration transfer requires that the new matrix fall within the spectral and physical variation space of the original calibration. Changing both the API and excipients fundamentally changes the matrix, and the existing calibration is expected to be **invalid** for the new formulation [S01 p.10].

Adding Raman does **not** make an invalid NIR calibration valid. Raman provides complementary molecular information (backbone and symmetrical non-polar groups vs. NIR's hydrogen bonds and asymmetric polar groups) [S01 p.15], but it does not restore validity to a calibration built on a different chemical system.

**What is actually required:**

A new calibration must be developed for the new formulation. The technical question is: which method or combination (NIR alone, Raman alone, or NIR+Raman) provides the best prediction of API concentration in the **new** blend?

**Recommended approach:**

1. **NIR diffuse reflection** remains the starting point for powder blend monitoring at the feed frame — this geometry is supported for pharmaceutical powder applications [S01 p.14-15].

2. **Raman (785 nm excitation)** is a valid comparison candidate for pharmaceutical blend monitoring [S01 p.15]. It may offer advantages if the new API has strong Raman-active features or if NIR bands overlap with excipients.

3. **NIR+Raman combination** (low-level data fusion) has demonstrated improved API prediction in pharmaceutical blends compared to single methods in some cases [S01 p.15], but this is a hypothesis to test, not a guaranteed gain [S01 p.14-15].

**Underlying assumption:** The new API and excipients are spectrally detectable by NIR and/or Raman. This must be verified experimentally.

---

## Measurement Concept

**Probe type and geometry:**
- NIR: diffuse reflection probe, flush-mounted at tablet press feed frame [S01 p.14-15]
- Raman: backscatter Raman probe; a multispectral NIRaman combined probe can fit inside the feed frame if co-located measurement is needed [S01 p.15, Fig.6]

**Fiber link:**
- NIR and Raman both operate in the range covered by standard Vis-NIR silica fibers (350–2400 nm) [S02 p.6-7]
- For Raman: Al/Cu-coated silica cables recommended to eliminate polymer jacket fluorescence [S02 p.7]

**Measurement location:**
- Tablet press feed frame (same as existing pilot)

*Note: Exact probe models, fiber lengths, and component ratings require AFS confirmation.*

## Risks & Uncertainty

- **Calibration invalidity is certain, not a risk:** The existing calibration cannot be assumed to work for the new formulation. The first experiment must build a new calibration, not test whether the old one transfers [S01 p.10].

- **Spectral overlap:** The new API and excipients may have overlapping NIR bands, reducing selectivity. Raman may or may not resolve this — it depends on the specific molecules.

- **Physical variation:** Particle size, density, and flow behaviour of the new blend will affect the NIR diffuse reflection signal. Scattering correction (MSC, SNV) will be needed, but calibration must include representative physical variation [S01 p.14-15, 17].

- **Reference method dependency:** The new calibration requires independent reference values (e.g. HPLC) for the new API in the new matrix. If these are not available, no calibration can be validated.

- **Combined method benefit is not guaranteed:** NIR+Raman fusion may or may not outperform the best single method for this specific formulation [S01 p.14-15]. This must be tested, not assumed.

- **Assumption:** The new API has detectable NIR and/or Raman spectral features distinct from excipients. If not, neither method will work.

## Feasibility Plan

**Objective:** Develop and compare calibration models for API concentration in the new formulation using NIR, Raman, and NIR+Raman, following the AFS multi-method test pathway [S05].

### 1. Samples
- Prepare powder blends of the **new** formulation spanning the full intended API concentration range
- Include deliberate variation in physical properties (particle size, blend time, humidity exposure) to represent realistic process variation
- Minimum sample count depends on matrix complexity and analyte range — this must be determined with AFS guidance; a pilot with too few samples cannot validate a calibration

### 2. Reference measurements
- Analyse each blend sample by an independent method (e.g. HPLC, content uniformity assay) validated for the new API
- Reference method must be independent of the spectroscopic measurement — it provides the "true" API concentration for calibration

### 3. Measurements to compare
- **NIR diffuse reflection:** Acquire spectra at feed frame geometry (or lab equivalent diffuse reflection probe)
- **Raman (785 nm excitation):** Acquire spectra at the same sample locations
- **Co-located NIR+Raman:** If using a combined probe, acquire both spectra from the same measurement spot to enable valid data fusion [S01 p.15]

### 4. Sequence
1. Build and validate single-method PLS regression models (NIR alone, Raman alone) using appropriate spectral pre-processing
2. If single-method performance is acceptable, select the better method
3. If neither single method meets the acceptance criterion, test low-level data fusion (merged spectral matrix) and compare to single methods [S01 p.15]

### 5. Go/no-go basis
- Define an acceptance criterion **before** the experiment (e.g. RMSEP < X% of label claim, R² > Y for independent validation set)
- The criterion must be agreed with the client and relevant to process control needs
- Do NOT use the original formulation's calibration performance as the benchmark — the new formulation is a separate problem

### 6. What this experiment demonstrates and does not demonstrate
- **Demonstrates:** Whether NIR, Raman, or NIR+Raman can predict API concentration in the new formulation with acceptable accuracy under controlled conditions
- **Does NOT demonstrate:** Long-term calibration stability, robustness to process upsets, or transferability to other formulations
- **Does NOT validate the old calibration:** The old calibration is expected to be invalid and should not be tested as if it might work
