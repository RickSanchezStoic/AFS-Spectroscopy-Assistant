# H01 — A New Formulation After an Existing NIR Pilot

**Customer Enquiry:**
> Our existing NIR pilot follows API concentration in one powder formulation at the tablet press feed frame. We are introducing a different API and excipient blend and would like to reuse the calibration. A colleague suggests adding Raman so that the old calibration will remain valid. What should our first technical assessment and experiment be?

---

## Requirements & Key Facts

**Stated by client:**
- Existing NIR diffuse reflection pilot monitors API concentration at the tablet press feed frame
- A different API and a different excipient blend are being introduced
- Goal: retain measurement capability across the formulation change
- A colleague has proposed adding Raman to preserve the existing NIR calibration

**Key unknowns:**
- Identity of the new API and new excipients; their spectral characteristics relative to the old formulation
- Concentration range and acceptance limits for the new API
- Whether the physical properties of the new blend (particle size, density, flow behaviour) differ from the old one
- Reference assay, its uncertainty, and sampling timing for the new formulation
- Feed frame access, cleaning conditions, and whether the probe installation changes

---

## Clarification Questions

1. What is the new API, and what are its main excipients? How do their near-infrared and Raman spectral features compare to the current formulation?
2. What is the required API concentration range and the acceptance limits that must be met?
3. How does the physical form of the new blend differ — particle size distribution, bulk density, flow rate — from the current one?
4. What reference assay will provide independent API concentration values for calibration of the new formulation, and what is its uncertainty?
5. Is the feed frame installation, probe type, and cleaning regime identical for the new formulation?
6. What response time and update rate are needed for process control?

---

## Recommendation

**Decision status: Provisional assessment — with an important correction to the stated premise.**

### Correction of the colleague's suggestion
Adding Raman does **not** preserve the validity of an existing NIR calibration when the API and excipients change. Each spectroscopic method — NIR and Raman alike — requires a calibration that is specific to the matrix it was built on. A change of API or excipients can invalidate a calibration regardless of which additional method is present [S01 p.10, worked example D01]. The two methods must each be re-calibrated on the new formulation independently before any combination is considered.

### NIR (diffuse reflection) — primary candidate
NIR diffuse reflection is directly supported for API blend concentration monitoring at the tablet press feed frame [S01 p.14–15]. It is the logical starting point because the existing hardware, probe installation, and process knowledge can be reused. A new, formulation-specific calibration must be built [S01 p.10].

### Raman — comparison candidate
Raman is a legitimate second candidate for the same application family [S01 p.14–15]. It offers higher chemical selectivity than NIR and may be less affected by physical variation in the powder (particle size, density) than NIR diffuse reflection [S01 p.11–12]. However, fluorescence background from the new API or excipients must be checked, and signal quality must be verified on representative samples before committing [S01 p.11].

### NIR + Raman combination
Consider only after each method has been assessed individually on the new formulation. Whether a combination adds predictive value is a hypothesis to test, not an assumption [S01 p.14–15].

## Measurement Concept

- **NIR:** diffuse reflection probe at the feed frame, same installation as the current pilot [S01 Table 1 p.6]
- **Raman:** Raman backscatter probe; excitation wavelength to be stated separately from the Raman shift range; probe type and installation require AFS confirmation [S01 p.11–12, Table 1 p.6]
- Both probes should ideally sample the same or adjacent location to allow direct comparison on the same material
- A combined probe measuring both simultaneously is an option to discuss with AFS, but probe type, optical configuration, and installation constraints need confirmation before specifying

---

## Risks & Uncertainty

- **Calibration invalidity is certain if not rebuilt:** the existing NIR calibration was built for a specific API and excipient matrix; it does not transfer to a different formulation [S01 p.10, D01 worked example]
- **Physical variation:** changes in particle size, density, or flow between the old and new blend will affect the NIR diffuse reflection signal independently of composition [S01 p.14–15]
- **Raman fluorescence background:** some APIs and excipients produce strong fluorescence that can mask the Raman signal; this must be measured on actual samples before the method is confirmed [S01 p.11]
- **No performance figures are stated here:** accuracy, update rate, and prediction error depend on the new formulation's spectra and the calibration design — none can be quoted without experimental data
- **Combination does not guarantee gain:** adding Raman alongside NIR may or may not improve prediction for this specific formulation; it must be demonstrated, not assumed

## Feasibility Plan

**Objective:** Determine which method (NIR, Raman, or both) can follow the new API concentration at the feed frame with acceptable prediction error, and establish whether the existing NIR hardware can be reused with a new calibration.

**Step 1 — Sample preparation**
Prepare representative blends of the new API and excipients across the agreed concentration range, spanning the physical variation expected in production (particle size, blend time, density variation).

**Step 2 — Reference measurements**
Collect independent API assay results for each blend using the agreed reference method, with documented uncertainty and timing.

**Step 3 — Spectral acquisition**
Record NIR diffuse reflection and Raman spectra from each blend under the feed frame conditions (or a representative laboratory proxy). Record both methods from the same sample where possible.

**Step 4 — Single-method calibration**
Build and cross-validate a NIR calibration on the new formulation first. Build a Raman calibration separately. Do not combine methods at this stage.

**Step 5 — Physical variation test**
Deliberately vary particle size and blend density within realistic bounds. Assess whether the prediction error remains within acceptance limits for each method independently.

**Step 6 — Comparison and decision**
Compare prediction error, bias, and robustness to physical variation for NIR alone, Raman alone, and (if warranted) a combined model on held-out batches. Select the simplest configuration that meets the client's acceptance criteria.

**Go / no-go basis:** Agree numerical acceptance criteria with the client before the experiment begins. The decision is based on prediction error and bias on independent material, not on laboratory blends used for calibration.
