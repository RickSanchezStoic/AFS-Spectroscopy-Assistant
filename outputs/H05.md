# H05 — AFS Spectroscopy Assessment

## Customer Enquiry

We have a liquid process that occasionally goes off specification. We suspect contamination, but we cannot yet name the contaminant or the affected quality variable. We would like you to recommend the best spectroscopy method and exact sensor configuration immediately. What information and first experiment should come before that decision?

---

## Requirements & Key Facts

**Client-stated facts:**
- Liquid process
- Occasional off-specification events
- Suspected contamination
- Contaminant is NOT yet identified
- Affected quality variable is NOT yet defined

**Key unknowns:**
- Identity of the contaminant (chemical class, concentration range, physical form)
- Which quality variable goes off-specification (and how it is currently measured)
- Liquid matrix composition (aqueous, organic, opaque, clear, viscous, etc.)
- Process conditions (temperature, pressure, flow rate)
- Whether off-spec samples have been retained for analysis
- Whether any reference analytical method exists for the quality variable
- Measurement location (in-line, at-line, bypass)

---

## Clarification Questions

1. **What quality variable currently defines "off-specification"?** Is there an existing laboratory test that detects the problem, and what does it measure?

2. **Have off-spec samples been retained?** If so, how many, and do you also have corresponding in-spec samples from the same process?

3. **What is the liquid matrix?** (e.g., aqueous solution, organic solvent, emulsion, suspension, petroleum-based, food-grade, pharmaceutical intermediate)

4. **What are the process conditions at the measurement point?** (temperature range, pressure, flow characteristics)

5. **Is the liquid optically clear, turbid, or opaque?** Does optical density change during or between batches?

6. **Do you have any hypothesis about the contaminant class?** (e.g., water ingress, particulates, degradation products, cross-contamination from another stream)

7. **Where in the process would measurement occur?** (main pipe, bypass loop, sample port, at-line station)

---

## Recommendation

**Decision Status:** Insufficient information

**Rationale:**

A spectroscopy method cannot be selected without knowing:
- **What spectral signature to look for** — every method (NIR, MIR ATR, Raman, UV-Vis, Fluorescence) detects different molecular features [S01 p.5-12]. Without identifying the contaminant or quality variable, there is no basis to predict which method would show a signal.
- **What reference measurement would validate a correlation** — calibration requires independent reference values for the target variable [S01 p.10].
- **Sample optical properties** — probe geometry (transmission vs. reflection vs. ATR) depends on whether the liquid is clear or scattering [S01 p.17-18].

Requesting an exact sensor configuration before this information exists would be speculation, not engineering.

---

## Measurement Concept

**Cannot specify at this stage.**

The appropriate first step is a multi-method exploratory test on retained off-spec vs. in-spec samples, using AFS's Multi-Spectral Fiber System covering 0.3–16 µm [S05]. This tests NIR, MIR ATR, Raman, Fluorescence, and UV-Vis simultaneously to identify which spectral regions show differences correlated with off-spec status.

Probe geometry and fiber type selection would follow from:
- Liquid optical properties (clear → transmission; turbid → ATR or diffuse reflection) [S01 p.17-18]
- Wavelength range of discriminating features (NIR → silica fiber; MIR → chalcogenide or PIR fiber) [S02 p.6-10]

---

## Risks & Uncertainty

- **No spectral method is guaranteed to detect an unidentified contaminant.** Some contaminants may be spectrally silent in all accessible regions, or present below detection thresholds.
- **Without a reference measurement, no calibration is possible.** A spectroscopic model requires paired data: spectrum + independent reference value [S01 p.10].
- **Off-spec events may have multiple root causes.** A single spectral signature may not capture all failure modes.
- **Sample representativeness is unknown.** If no off-spec samples have been retained, exploratory testing cannot proceed.
- **Matrix variability may confound detection.** Physical changes (temperature, turbidity, flow) can produce spectral variation unrelated to contamination [S01 p.14-15, 17].

---

## Feasibility Plan

**What must come before method selection:**

1. **Samples:**
   - Collect and retain multiple off-spec samples AND corresponding in-spec samples from the same process period.
   - Include samples spanning the normal process variation (not just "perfect" in-spec samples).
   - Minimum sample count depends on matrix complexity; a pilot study with fewer than ~10 off-spec and ~10 in-spec samples is unlikely to yield statistically meaningful discrimination — exact count to be agreed with AFS based on process variability.

2. **Reference measurements:**
   - Define what independent analytical method currently identifies off-spec status (even if qualitative, e.g., "fails QC test X").
   - If the contaminant becomes identified, establish a quantitative reference method (e.g., GC-MS, HPLC, Karl Fischer for water, etc.).

3. **Measurements to compare:**
   - Submit samples to AFS Multi-Spectral Lab Test [S05].
   - Acquire spectra using multiple methods simultaneously: NIR (transmission and/or diffuse reflection), MIR ATR, Raman, UV-Vis, Fluorescence.
   - Use chemometric analysis (e.g., PCA) to identify which spectral regions discriminate off-spec from in-spec samples [S01 p.14-15; S05].

4. **Sequence:**
   - Exploratory PCA on each method separately to find discriminating features.
   - If multiple methods show discrimination, evaluate single-method models before considering combinations [S01 p.7-9].

5. **Go/no-go basis:**
   - Agree with client on an acceptance criterion BEFORE the experiment (e.g., "spectral method must correctly classify ≥90% of off-spec samples in a blind validation set").
   - Do NOT invent this threshold — it must reflect the client's operational risk tolerance.

6. **What this experiment demonstrates:**
   - Whether ANY spectral method shows a reproducible difference between off-spec and in-spec samples.
   - Which spectral region(s) and method(s) are candidates for further development.

7. **What this experiment does NOT demonstrate:**
   - Root cause of contamination.
   - Quantitative concentration of contaminant (requires identified target + calibration).
   - Long-term stability of a process model (requires validation over time and process variation).
